# SmartRoute AI - Documentation (`/docs`)

System architecture, design specifications, and integration references for SmartRoute AI.

## Index
1. **Architecture Overview**: Emergency-aware routing system connecting dispatchers, citizens, and hospital telemetry.
2. **Backend API Reference**: FastAPI endpoints, schemas, and PostGIS queries.
3. **External Integrations**:
   - OpenRouteService (ORS) matrix and directions API.
   - Open-Meteo weather API.
   - Neon Serverless PostgreSQL with PostGIS extension.
4. **Data Models**: PostGIS spatial tables for road segments, hospital points, accident reports, and emergency vehicle locations.
